SafeVision AI — Production-style Frontend Patch
================================================

الهدف
-----
هذه الحزمة تعيد تنظيم واجهة Streamlit دون حذف أو تعطيل مرحلة اكتشاف الأجسام.
الصورة الناتجة من YOLO مع Bounding Boxes واسم الفئة وConfidence هي النتيجة
الرئيسية، وتظهر مباشرة بعد انتهاء التحليل، وليست داخل تقرير مغلق.

ما الذي تغير؟
-------------
1) واجهة داكنة حديثة ومنظمة مع Sidebar للإعدادات وحالة الموديل.
2) أوضاع منفصلة تماماً: Image / Video / Camera / Model guide.
3) في وضع الصور: يعرض التطبيق الصورة المعلّمة افتراضياً، مع إمكانية التبديل
   للصورة الأصلية، وبجوارها ملخص الأجسام المكتشفة والفئات والأعداد.
4) جدول Detection Records يظهر مباشرة ويمكن تنزيله CSV.
5) تنزيل الصورة المعلّمة PNG.
6) في وضع الفيديو: يعرض الفيديو الناتج بعد رسم الـdetections عليه مباشرة،
   بجانب ملخص الأعداد المجمعة من الإطارات المعالجة، مع تنزيل MP4 وCSV.
7) الكاميرا منفصلة عن رفع الملفات، وتلتقط صورة ثابتة ثم تستخدم نفس مسار الصورة.
8) التحقق من ملفات الصور، وحدود لحجم الملفات، ورسائل أخطاء أوضح.
9) لا توجد أي تغييرات على بنية الموديل أو أوزانه أو Dataset.
10) الاحتفاظ بتثبيت pyarrow==18.1.0 لتفادي تعارض PyArrow مع NumPy 1.26.x.

طريقة التركيب على Windows
-------------------------
1) فك ضغط SafeVision_Production_Frontend_Patch.zip.
2) انسخ app.py إلى جذر المشروع:
   C:\NTI\SafeVision_AI_Torch\app.py
   واختر Replace.
3) لا تستبدل ولا تحذف app\inference.py.
4) احتفظ بملف requirements.txt الحالي. إذا لم يكن يحتوي على
   pyarrow==18.1.0، أضف السطر.
5) افتح PowerShell داخل مجلد المشروع وشغّل:
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
6) أوقف التطبيق القديم بـ Ctrl+C ثم شغّل:
   .\run_app.bat

مهم جداً: الحفاظ على Bounding Boxes
-----------------------------------
تعتمد الواجهة على run_image() لإرجاع:
- annotated image كـ NumPy RGB array (H, W, 3)
- counts
- rows
ويجب أن تكون الصورة annotated مرسومة من YOLO result.plot(pil=True) أو مكافئ
يرجع RGB. لا تحذف هذا الجزء من inference.py. إذا اختفت الصناديق من الصورة
الناتجة، افحص run_image() في app\inference.py وليس CSS أو الواجهة.

ملاحظات تشغيل
-------------
- لم يتم تعديل app\inference.py أو طريقة عمل run_video().
- وضع الكاميرا يلتقط صورة ثابتة باستخدام Streamlit camera_input، وليس بثاً حياً.
- الفيديو يعرض counts على مستوى الإطارات وليس الأشخاص الفريدين.
- الواجهة لا تربط كل no_* region بعامل بعينه.
- تم فحص Syntax للملف فقط. يجب اختبارها على Windows مع البيئة والأوزان الفعلية.

تنبيه Production
----------------
هذا تحديث واجهة Production-style داخل Streamlit. النشر التجاري الحقيقي يحتاج
أيضاً إعدادات مصادقة وصلاحيات، إدارة جلسات وبيانات، حدود تخزين ورفع، Logging،
مراقبة، نسخ احتياطي، واختبار حمل وأمان. لا تعتبر الواجهة وحدها اعتماداً أمنياً
أو تشغيلياً لنظام سلامة ميداني.
